# Reproduction scope and evidence layers

The package distinguishes transport integrity, structural export checks, saved-result compilation, fixed-record aggregation, saved-policy evaluation, fresh training and optimization. Only the exact executed command and its readable exit result establish coverage. Listing code, copying a saved result or checking a digest does not establish a numerical reproduction.

The exported algorithms, scalar values, typed numerical arrays and declared protocol identities are preserved from authenticated scientific records. Package/module naming and selected descriptive metadata have been normalized, with a private source-to-export map and payload-equivalence checks. File hashes can change after a metadata rename even when every numerical value remains identical. Scientific identifiers, seed integers, policy modes, array order and original protocol digests are not aesthetic labels to be rewritten.

Independent validation of the numerical archive was completed on 22 October 2026 for the scopes in [VALIDATION.md](VALIDATION.md). This documentation-only distribution preserves the tested executable/scientific payload, whose exact hashes are recorded in `manifests/validated_payload.json`. Full numerical execution is carried from those authenticated results, not claimed to have been repeated during the documentation update. Biological continuation, new melanoma execution and clean numerical installation remain unestablished. All future code or protocol changes require their own validation.

The recorded 22 October isolated installation attempt failed at package-index DNS resolution before NumPy was installed. That is an access failure, not evidence of dependency incompatibility. Running the standard-library verifier with site imports disabled checks isolation of that operation only; it is not a virtual-environment installation or a numerical clean-install pass.

Floating-point and hardware identity matter. Cross-host DDQN training can diverge despite matched random keys. Exact state checks, random-state checks, model tolerances, aggregate tolerances and PDF transport hashes are different criteria. Do not weaken a recorded threshold to obtain agreement. Where numerical comparisons are retained, report exact agreement separately from agreement within the declared tolerance.

The continuing synthetic software-check path has reserved seeds and a bounded horizon. The biological continuation path requires the exact recorded environment plus original authorization and input identities. A successful environment comparison alone is not authorization for new production runs. Raw biological continuation remains unavailable without the separately permitted external files.

A numerical output must never replace `results/` automatically. New output directories are mandatory and external. Failed, interrupted or debug/validation records do not become scientific observations. Evaluation checkpoints and paired longer-budget continuations do not become additional independent seeds.

The computational guide retains its printed article-reference numbers but does not create local-file hyperlinks to an unbundled manuscript.
